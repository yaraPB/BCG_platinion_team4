The problem with detours

A detour only works if a road still connects the two places.

Navigation apps assume you can always drive around a closure. In fragile regions that breaks down: when a river floods, every bridge can go at once and the road network splits into separate islands. The port and the camp end up in different networks with no road between them. Planning a better route doesn't help. You need a different supplier.

↻Tier 1 · Reroute

Road closed, network still connected

Same supplier, new path. Shortest alternate route on the live graph with Dijkstra(G − closed). Drivers get the detour by SMS.

⇄Tier 2 · Re-source

Network split, destination stranded

Find the connected component that contains B, then the closest supplier C inside it that has stock: argmin d(B, s), s ∈ K(B). CB is longer than AB, but it's a route that exists.

✈Tier 3 · Airlift / escalate

No supplier left in reach

B's component has no stock or B is fully isolated. The shortfall is escalated to the nearest airstrip with stock, a river barge or a cross-border corridor, and partners are alerted.

How the Lifeline Engine works

From weather alert to a dispatched fallback in four steps.

1

Model the network as a graph

Ports, warehouses, farm co-ops, camps and clinics are nodes. Roads, bridges, ferries and passes are edges, weighted by travel time and road condition.

2

Read the world state

Rainfall and river forecasts, cyclone tracks, conflict events and driver reports become a failure probability for every road at each forecast horizon.

3

Simulate thousands of futures

We sample road failures, recompute connectivity and allocate stock by IPC priority, then measure how often each site loses its supply line.

4

Act before the road is gone

Pre-position stock at fallback depots, send deliveries early, push detours to drivers by SMS and put airlift on standby, all before the closure happens.

# runs on every closure report or forecast update
def replan(G, closed, offline):
    G' = G − closed − offline
    K  = connected_components(G')
    for B in sites.sorted(by=IPC_phase, people):
        A = primary_supplier(B)
        if A in K[B]:                 # Tier 0/1
            route = dijkstra(G', A, B)
        else:                          # graph split
            S = suppliers ∩ K[B] with stock  # Tier 2
            C = argmin(S, key=dist(B, ·))
            if not C: airlift_or_escalate(B)  # Tier 3
        stock[C] −= demand[B]

# prediction: P(road fails) from hazards × exposure
for i in range(2000):
    closed = {e : rand() < p_fail(e, horizon)}
    stats += replan(G, closed, offline)
